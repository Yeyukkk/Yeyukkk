# Alpha 01 · 上传与缺口清单

## 首批允许审查后上传
- Alpha 01 现行项目目标与最新研究阶段回执（清除个人和账户资料）。
- 当前基本面筛选规则、数据字段字典、不可变研究/决策日志。
- 不含授权受限原始行情的摘要研究与公开来源链接。
- Codex 可公开代码的版本信息、测试回执、数据来源说明。
- Muse 前向观察的非敏感摘要和有效时间、失败样本及局限性。

## 必须先做权限核对
- 大型数据或 ZIP：检查是否混有个人/账户数据、密钥、许可行情、日志或内部证据。
- 任何来自其他项目的源：默认不得进入 Alpha 01。
- 未确认可公开/可再分发时保持本地，不上传。

## 第一批交接的验收
- 清单中每个文件都有 `original_path`、`sha256`、`source_as_of`、`owner`、`evidence_level`。
- GitHub PR 列出所有新增与替换，未改冻结历史。
- Muse、Codex 分别在自己的环境实际拉取同一 commit 并回执，否则只记 `PUBLISHED_NOT_SYNCED`。
